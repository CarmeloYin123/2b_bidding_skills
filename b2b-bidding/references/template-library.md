# 历史案例与模板库

原始资料由用户在项目工作区中提供。执行前确认其版本、授权范围和适用性；保留原文件，只在项目工作目录中创建副本。

## 已知配对与用途

| 优先级 | 原始文件 | 用途 | 主模板适用范围 |
|---|---|---|---|
| 最高 | 已去标识化的完整投标文件与配对响应案例 | 招标文件与对应投标响应案例 | 适用于资格、商务、技术、价格分册和逐条响应齐全的项目 |
| 最高 | 已去标识化的询比采购文件与配对响应案例 | 询比采购文件与对应响应案例 | 适用于响应函、报价、商务材料、响应方案、偏离表和点对点应答齐全的项目 |
| 专用 | 项目与报价评估表 | 项目/报价评估 | 评估客户、市场、产品、预算、报价策略、标书注意点和中标机会 |
| 专用 | 工作量与报价依据工作簿 | 工作量与报价依据 | 汇总角色工作量、单价和报价依据；新项目不得沿用历史数值 |

## 模板选择规则

1. 采购方提供的格式、平台节点或暗标规则优先，直接以其为主模板。
2. 与本项目招标文件一一配对的历史响应文件优先于其他案例。
3. 同采购方式和同交付类型的已授权案例优先；询比采购优先选用询比响应结构，完整投标优先选用分册结构相近的响应案例。
4. 选择一个主模板；其他案例只作为局部参考。记录“选用模板、原因、保留部分、替换槽位、不可复用内容”。
5. 标书结构、章节名、顺序和表格以招标文件为准；历史案例不能覆盖项目专有格式。

## 历史样例的可复用结构

### 完整投标案例

主结构为：资格审查文件 → 商务标部分 → 技术标部分。常见槽位包括营业执照、法人资格证明、授权委托、社保、资格证明、保证金、投标函、投标人基本情况、商务响应、服务承诺、财务材料、技术条款总体响应、项目认识与分析、进度及质量保障、整体解决方案、实施/项目管理、售后服务及案例。适用于要求完整资格和多分册响应的项目。

### 询比采购案例

主结构为：响应函 → 授权委托书 → 响应保证金 → 报价表（总表/分项） → 商务材料（公司、资质、财务、案例、人员） → 响应方案（性能指标、售后、实施、验收、偏离表、点对点应答、详细建设方案）。适用于询比采购和技术服务项目。

不要因案例有某个章节而默认新项目也需要它；以新项目格式和应答矩阵为准。

## 格式保真操作

1. 先创建项目工作副本；原始案例不得改写。
2. 用原案例中的目录、样式、编号、表格、页眉页脚、封面、附件位置和分页方式作为格式权威，除非招标文件另有格式。
3. 用样式替换和原表填充，不用手工重建类似格式。保留未改的关系、页眉页脚、目录域、编号、印章/图片占位与表格设置。
4. 逐槽替换项目名称、编号、采购人、日期、主体、授权、报价、人员、案例和技术内容；全文搜索旧客户、项目、日期、金额、电话、账号、敏感名称和占位符，确认无残留。
5. 每次重大编辑后渲染 DOCX 并检查所有页；特别检查封面、目录、表格跨页、页码、签章、附件和 PDF/平台导出效果。

## 公司默认版式与历史模板的关系

默认版式执行 [响应文件编写标准](response-authoring-standard.md)：全文宋体；一级至六级标题依次使用小二、三号、小三、四号、小四、五号，正文及表格正文使用小四；标题左对齐、正文两端对齐，左右缩进均为 0、无特殊缩进、段前段后均为 0、1.5 倍行距。历史模板中的仿宋正文、首行缩进、英文 Times New Roman 或其他遗留格式不是默认格式。

因此：招标文件/补遗/平台明确格式 > 项目指定模板的明确格式 > 公司默认版式 > 历史案例遗留样式。实施公司默认版式时，不得破坏采购方模板中的目录、编号、表格、页眉页脚、分节、签章或附件功能。
