# 招投标 Skill 改进日志

## 2026-07-20 — 模块化重构

- 来源：用户授权的 skill 架构评审与改进请求。
- 匿名化观察：拆标、编标、规范审查、递交管控的输入/输出差异较大；单一 skill 的触发范围和默认提示不够聚焦，且质量规则有重复维护风险。
- 改动：将 `b2b-bidding` 收敛为总控；新增拆标、编标、规范审查、递交管控和 skill 维护五个同级 skill；新增项目工作包、会话复盘机制，并将递交门禁与共用规范性检查分离。
- 风险：低。未变更任何公司政策、审批阈值、联系人、价格、法律结论、知识产权或源码规则。
- 验证：运行 skill 结构校验、检查子 skill 的引用路径与无 TODO 占位；后续以去标识化案例回放各子流程。
- 回滚：删除五个新增子 skill，并恢复总控与递交质量门的前一版本。
