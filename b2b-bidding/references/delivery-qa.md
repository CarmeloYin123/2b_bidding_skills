# 交付、冻结与递交质量门

内容与版式的共用检查标准见 [规范性评估](compliance-review.md)。本文件只处理报价审批到归档的阶段门禁。

## 冻结前

- [ ] `requirements-matrix.md` 的 P0/P1 均有最终标书定位、证据、责任人和审核状态。
- [ ] `review-report.md` 无 P0；关键 P1 已闭环或有已批准的例外结论。
- [ ] 销售、产品/技术已确认各自负责的客户口径、技术可交付性、资源、工作量和交付周期。
- [ ] 报价范围、数量、税率、价格口径与技术/合同边界一致，且当前授权链已审批。
- [ ] 合同、知识产权、源码、数据、付款、验收、赔偿和违约风险已有明确结论。
- [ ] 最终候选版完成交叉审核，销售确认与重大项目知悉/确认均有留痕。

## 用印与递交

- [ ] 递交版本已冻结；用印/电子签章版本与冻结版本一致。
- [ ] 文件名、分册、正副本/份数、格式、大小、目录位置、扫描清晰度符合项目要求。
- [ ] 签字、盖章、骑缝、密封、CA、加密/解密、封条和接收地址均已逐项核对。
- [ ] 平台上传后保存成功回执、截图和最终上传文件；线下递交保存快递/签收凭证。

## 收尾

- [ ] 开标/讲标以冻结版为唯一口径；结果和原因已由销售反馈。
- [ ] 归档最终文件、审批、用印、递交证据、结果和去标识化复盘。
- [ ] 将可复用问题模式更新到项目 `lessons.md`，供授权后的 skill 复盘使用。

任何 P0、未审批报价、红线未决、资格/主体不匹配、签章缺失或递交规则不明均为阻塞项；不得以“后续补”放行。
