# B2B标书规范审查

默认只读审查，不改写源文件。先读取共享资料 `../b2b-bidding/references/compliance-review.md`、`template-library.md`、`project-pack.md` 和 `requirements-matrix.md`。

收集候选标书、招标文件/补遗、平台规则、项目格式、批准的报价/合同结论与选定模板。缺少招标文件时，只评价公司基线与模板符合度，明确“未验证项目级资格、评分、格式和递交要求”。

对 DOCX 使用 documents skill 提取结构、样式/章节证据并渲染逐页检查；对 PDF 提取文本并渲染每页；对 XLSX 附件使用 spreadsheets skill 检查公式、数值、表格与格式。文本提取不替代视觉检查。

分别给出：项目招标文件符合度、公司流程/红线符合度、模板与版式保真度。逐项检查资格与主体、技术应答、商务报价、合同红线、评分附件、全文一致性、目录编号、表格扫描件、页码与递交文件。输出问题清单：级别、类别、依据、精确定位、发现、影响、整改动作、责任人。

P0 为废标/硬截止/红线，P1 为实质性或重大评分/一致性，P2 为规范性或可读性。存在 P0、未审项目级要求或关键 P1 未闭环时，不得给出“符合/可递交”结论。将报告保存或回填为 `review-report.md`，供递交管控使用。
