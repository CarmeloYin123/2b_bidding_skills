# 2B Bidding Skills

一套通用的 B2B 招投标工作流技能，包括项目总控、拆标分析、应标编写、规范性审查、递交管控和复盘维护。

## 目录

- `b2b-bidding/`：跨阶段项目总控与工作包规则。
- `bid-tender-analysis/`：招标文件拆解、应答矩阵和风险清单。
- `bid-authoring/`：基于已批准内容和模板的响应文件编写。
- `bid-compliance-review/`：内容、格式与一致性审查。
- `bid-submission-control/`：冻结、用印、递交和归档门禁。
- `bid-skill-maintainer/`：基于授权、去标识化证据的持续维护。

## 使用边界

- 项目文件、补遗、平台规则和批准结论优先于本仓库的通用规则。
- 不将客户信息、报价、人员材料、合同、证件、源代码、账号或其他项目敏感材料提交到本仓库。
- 任何金额阈值、审批链、资质、合同或知识产权结论，均须使用当前项目的有效授权资料复核。

本仓库仅包含去标识化的通用流程和检查规则，不包含原始招投标文件、历史案例或内部资料。
