# B2B招投标技能复盘

仅在用户明确要求维护、或已授权的自动复盘任务触发时使用。先读取共享资料 `../b2b-bidding/references/improvement-loop.md`，再使用 skill-creator 的流程更新目标 skill。

只审查用户授权的、与B2B招投标有关的会话摘要、项目复盘、反馈和工作区资料；不读取或记录无关会话，不把客户名称、联系人、报价、合同、证件、源代码或其他敏感原文写入 skill 或改进日志。

当出现至少两项独立重复问题、用户明确反馈、新模板/流程资料进入参考包，或定期安全检查发现过期/冲突时，建立改进候选。将每项候选记录为：来源类型与日期、匿名化观察、影响 skill、建议、风险等级、是否需要业务确认、验证方式和状态。

可自动做低风险改动：路由/触发词澄清、检查项补充、示例和模板卡索引、格式/工具步骤修正。公司政策、金额/审批阈值、联系人、资质、法律合同结论、知识产权/源码边界、删除历史规则或重大架构改动只能记录为待确认提案，除非用户在当前任务中明确授权。

每次更新后运行 skill-creator 验证；对受影响的工作流用去标识化样例进行回放检查；记录变更、依据、验证和回滚方式。若证据不足或没有触发条件，结束时明确“本次无变更”。
